# Hero Image

Drop a photo here named exactly `hero.jpg` (e.g. a farm/crop field photo,
morning light works well with the current overlay tint) and the Home
screen's hero block will use it automatically — no code changes needed.

Suggested free, no-attribution-required sources: unsplash.com, pexels.com.
Search something like "farm field morning" or "crop rows sunrise."

If no hero.jpg is present, the hero still displays a warm gradient as a
fallback, so nothing breaks either way.
